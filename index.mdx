BenRover est un environnement ROS 2 permettant de tester le déplacement, les
capteurs, l'odométrie et la cartographie d'un rover dans un monde simulé.

## Parcours recommandé

1. Préparer et construire le workspace.
2. Démarrer la simulation.
3. Vérifier les topics et le TF.
4. Lancer la cartographie.
5. Lancer l'intégration complète.
6. Tester la supervision.
7. Sauvegarder la carte.

## Commandes essentielles

```bash
cd ~/Projects/BenRover
source /opt/ros/humble/setup.bash
colcon build
source install/setup.bash
```

```bash
ros2 launch benrover_gazebo spawn_benrover.launch.py
```
